# AirWrite

Write letters and draw gestures in the air with a WitMotion WT9011DCL sensor.
Open the page in Chrome or Edge (computer or Android) and click **Connect sensor**.

This Space is deployed from the AirWrite project with `scripts/deploy_hf_space.sh`.
